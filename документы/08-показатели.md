# 08. Показатели и сводка начальнику

[К содержанию](../README.md) · [Далее: решения и риски](09-решения-и-риски.md)

## Основа расчёта

Каждая сводка имеет момент среза и версию списка волны. Единица расчёта — уникальное АРМ из этого списка, а не количество задач, пользователей, попыток установки или подключений.

Для удалённых рабочих мест используется согласованная единица учёта. Устройство регионального сотрудника, с которого он подключается к московскому АРМ, не добавляется в физический объём миграции.

Обозначения: **N** — число АРМ в версии списка; **A** — только Astra; **D** — Astra вместе с Windows; **W** — подтверждённая Windows без Astra; **U** — конфигурация не подтверждена. Для одного среза категории не пересекаются.

```text
N = A + D + W + U
Astra установлена на момент среза = A + D
Доля АРМ с установленной Astra = (A + D) / N × 100%
Доля АРМ только с Astra = A / N × 100%
Подтверждённо сохраняют Windows = D + W
Неподтверждённая конфигурация = U
```

При N = 0 процент обозначается «не применяется», а не 0% или 100%. Если состав версии неизвестен, процент вообще не рассчитывается до уточнения основания.

## Исторический факт и текущее состояние

Отдельно можно показать число АРМ, на которых установка Astra была когда-либо подтверждена в рамках рассматриваемой волны. Этот показатель сохраняет историю, но не заменяет текущий результат.

Пример: Astra была установлена, затем для восстановления работы возвращена конфигурация только Windows. Первоначальная задача установки остаётся исторически выполненной; текущий отчёт относит АРМ к W. Необходимые повторные работы учитываются отдельно.

Повторная установка того же АРМ не увеличивает количество уникальных АРМ. При сводке по нескольким волнам нельзя просто складывать их объёмы, если одно АРМ встречается в нескольких списках: используется объединение идентификаторов и единое состояние на момент среза.

## Минимальная сводка

| Показатель | Что показывает | Чего не доказывает |
|---|---|---|
| Astra установлена сейчас | Формальный результат миграции с учётом двойной загрузки | Что сотрудник выполняет всю работу в Astra |
| Только Astra | Windows не сохраняется по подтверждённым сведениям | Отсутствие инцидентов |
| Двойная загрузка | Промежуточный результат и обязательство по выводу Windows | Нарушение сервиса само по себе |
| Не подтверждено | Пробел в сведениях | Что Astra отсутствует или точно установлена |
| Требуются ручные работы | Очередь действий сопровождения по текущему плану | Что у площадки уже выделены ресурсы |
| Открытые инциденты | Число незавершённых обращений | Число затронутых АРМ: оно считается отдельно |
| Зависимости без решения или прогноза | Где требуется действие профильного подразделения | Гарантированную дату полного перехода |

Общие инциденты считаются по уникальным номерам, а затронутые АРМ — по уникальным идентификаторам. Не следует называть долю связанных обращений «процентом ошибок миграции», пока не подтверждена причина каждого нарушения.

## Изменения списка волны

Состав имеет исходную и при необходимости текущую утверждённую версии. Изменение сопровождается основанием, автором решения, временем и сравнением объёмов. Перенос проблемного АРМ в другую волну не может незаметно улучшить предыдущий отчёт.

Если принято завершить волну с перенесёнными работами, это показывается как управленческое закрытие с остатком обязательств, а не как установка на всех исходных АРМ. Закрытие самой волны, установки и вывода Windows — разные события.

## Свежесть сведений

В отчёте видно время среза и давность подтверждений. Правило, после какого срока сведения требуют повторного подтверждения, согласуется отдельно. Отсутствие нового подтверждения нельзя автоматически превратить в удобную текущую конфигурацию.

Поздно полученное событие отражается в следующей сводке или её явно обозначенном исправлении. Противоречивые источники выделяются для уточнения.

## Вымышленный пример

В [наборе из 12 АРМ](../примеры/02-данные.json): A = 4, D = 3, W = 4, U = 1. Поэтому сейчас Astra установлена на 7 из 12 АРМ, или 58,3%; только Astra — на 4 из 12, или 33,3%. Исторически установка подтверждалась на 8 АРМ; одно из них возвращено к Windows.

Один открытый инцидент относится к АРМ с установленной Astra. Он показывается отдельно и не вычитается из факта установки.

[Готовая сводка по этим данным](../примеры/03-сводка.md) содержит не только числа, но и вопросы для управленческого решения.
