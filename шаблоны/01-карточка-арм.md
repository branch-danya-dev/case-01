# Карточка контроля миграции АРМ

[К содержанию](../README.md) · [Правила учёта](../документы/04-учёт-и-состояния.md)

Форма показывает состав сведений в Service Desk. Квадратные скобки обозначают место для значения. Это не отдельный реестр, заменяющий систему.

| Поле | Значение или источник |
|---|---|
| Идентификатор АРМ | [Устойчивый идентификатор из реестра] |
| Площадка и тип АРМ | [Ссылка на сведения владельца реестра; физическое или удалённое] |
| Ответственный на площадке | [Разрешённая ссылка на действующую запись] |
| Волна и версия списка | [Номер, версия, источник] |
| Плановый срок | [Значение из согласованного плана] |
| Текущая конфигурация | [Windows / Astra + Windows / Только Astra / Не подтверждено] |
| Основание конфигурации | [Источник, время события, разрешённая ссылка] |
| Задача установки | [Номер, состояние, текущая группа] |
| Следующее действие | [Что выполнить и кто выполняет] |
| Контрольный срок | [Когда получить результат или повторно уточнить] |
| Причина ожидания | [Конкретное препятствие и связанная задача] |
| Задача вывода Windows | [Связь обязательна при двойной загрузке] |
| Инциденты | [Связанные номера; отсутствие инцидента не предполагается по закрытию установки] |
| История | [Ссылка на события и предыдущие работы, включая восстановление Windows] |

Перед включением в сводку проверить идентификатор, отсутствие дублирующего участия в волне и наличие источника текущего состояния. Неизвестные сведения отмечать явно, а не заполнять предположениями.
