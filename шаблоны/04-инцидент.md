# Сведения об инциденте, связанном с работами миграции

[К содержанию](../README.md) · [Порядок контроля](../документы/07-инциденты-и-контроль.md)

Форма дополняет действующую карточку инцидента, а не заменяет её обязательные поля и правила.

| Поле | Содержание |
|---|---|
| Номер обращения | [Номер Service Desk] |
| Затронутые АРМ | [Один или несколько идентификаторов] |
| Нарушенная функция | [Что конкретно сотрудник не может выполнить] |
| Время обнаружения | [Дата и время] |
| Влияние и срочность | [Подтверждённые сведения для действующей шкалы приоритета] |
| Текущая конфигурация | [ОС и источник сведений, без закрытых параметров] |
| Связанные работы | [Задача установки или вывода Windows] |
| Первичная проверка | [Что проверено в пределах полномочий, результаты] |
| Текущая группа | [Назначенная группа по действующему процессу] |
| Следующее действие | [Конкретное действие и исполнитель] |
| Контроль и срок обслуживания | [Следующая проверка состояния; отдельно срок по действующему SLA] |
| Временное восстановление | [Разрешённый способ и результат, если применялся] |
| Основание завершения | [Подтверждение восстановления по действующему процессу] |
| Оставшиеся обязательства | [Вывод Windows, повторная установка, работа по общей причине] |

Связь с миграцией не означает доказанной причины сбоя. Переадресация не является восстановлением. Закрытые материалы передаются только разрешённым способом.
